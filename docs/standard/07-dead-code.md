# 07 - 死代码

判定前必须查完「检索范围」。少查一栏，不得下「确认无引用」。

## 检索范围

| 范围 | 查什么 |
|------|--------|
| 生产代码 | `src` 里测试以外的引用，含类型与再导出 |
| 测试 | 路径含 `/__tests__/`，或文件名含 `.test.` |
| 脚本 | `scripts/`，以及 `package.json` 的 scripts |
| 配置 | 构建、CI、Next、TypeScript 配置里的路径和符号 |
| 可执行字符串 | 动态 `import()`、路由字符串、注册表中的名字 |

历史文档里的名字不算引用。plans、summary、长文中出现该符号，不构成引用。

## 判定

| 结论 | 条件 | 动作 |
|------|------|------|
| 确认无引用 | 检索范围零命中 | 在当前改动里删除该导出或文件 |
| 疑似 | 还要核实产品是否保留、是否预留骨架、是否手工脚本入口 | 不删。删除前写明还要核实什么 |
| 只在测试里使用 | 生产代码零命中，测试有命中 | 保留。不是死代码 |
| Next.js 约定 | `page`、`layout`、`template`、`loading`、`error`、`not-found`；`route` 的 HTTP 方法导出；`sitemap`；`metadata` | 搜不到 import 也保留。不是死代码 |

疑似改为确认无引用之前，写明核实结果。产品要保留、是预留骨架、或是手工脚本入口的，继续不删。

## 预留骨架

文件头写明「预留」的骨架算疑似。没有调用方也不删。

| 路径 | 处置 |
|------|------|
| `src/lib/api/apiKey.ts` | 疑似。保留 |
| `src/lib/api/quota.ts` | 疑似。保留 |

## 未使用的导出

| 情况 | 动作 |
|------|------|
| 符号在本文件内仍被使用，只是多写了 `export` | 只删多余的 `export` |
| 本文件内和文件外都没有使用 | 删符号 |
| 测试锁定了现有行为 | 不改行为。不为清理去改测试所锁定的行为 |

## 注释

| 内容 | 动作 |
|------|------|
| 注释掉的旧实现 | 不入库。旧实现留在 git 历史 |
| 说明性注释 | 可以留 |
