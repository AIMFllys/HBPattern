# HBPattern 前端深度优化计划

> 📦 **完整的、可执行的前端优化任务包**  
> 🤖 **每个文档 = 一次完整的 AI 交互会话**  
> ⏱️ **预计总周期**: 4周（42小时）

---

## 📖 快速开始

### 第一次使用？

1. **阅读总览**: 打开 `00-overview.md` 了解整体规划
2. **选择会话**: 从 `01-phase0-tech-debt.md` 开始
3. **复制粘贴**: 将文档全文复制给 AI（如 Claude、GPT-4、Kiro）
4. **执行验证**: 按照文档中的验证方法检查结果
5. **继续下一个**: 完成后进入下一个会话

### 为什么这样设计？

- ✅ **自包含**: 每个文档包含该阶段所需的全部信息
- ✅ **可追踪**: 明确的验收标准，便于检查完成度
- ✅ **渐进式**: 按优先级排序，可以逐个执行
- ✅ **可中断**: 随时可以停止，下次继续

## 💡 使用技巧

### 给 AI 的指令模板

```
你好！我正在进行 HBPattern 前端深度优化。

请帮我完成：[文档名称]

[复制整个文档内容]

请严格按照文档中的：
1. 实施步骤执行
2. 验收标准检查
3. 注意事项遵守

完成后请总结：
- 完成了哪些任务
- 修改了哪些文件
- 如何验证结果
```

### 遇到问题？

1. **依赖未满足**: 先完成依赖的会话
2. **Bug 阻塞**: 回到 Phase 0 确保基础修复
3. **不确定如何验证**: 查看文档的"验证方法"章节
4. **技术栈不熟悉**: 查看文档的"上下文信息"章节
